## Бюджет для будущих сеансов

Лимиты составляют 45 аккаунтных и 18 проверочных вызовов за скользящую минуту. SDK-котировка резервирует до девяти вызовов до первого чтения. Неизрасходованный остаток возвращается сразу. Тихим адресам оставляется запас на котировку, для BUY и SELL выделяются резервы. Резервы адреса и фазы могут совпадать. При занятой котировке следующий запрос получает локальный отказ. Для проверок источника и пакетной финальности действуют отдельные резервы внутри лимита 18. HTTP 429 вводит общую 30-секундную паузу. Правила относятся к будущему процессу.
